# Dark theme

Today, Recipe, the allergen notice with a rebalance proposal, No profile on this phone, an import fallback with the no-profile block, and Where your data lives in the dark theme, composed from FitMeal components on 375 × 780 iPhone frames. A showcase page, not a component: build the SwiftUI screen from the components it uses.

Every other screen renders in dark by passing `theme: 'dark'` to its `PhoneFrame`; all colour comes from tokens.
