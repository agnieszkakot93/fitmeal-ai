# PhoneFrame

An iPhone-sized frame (375 × 780) for showcase pages. The status bar and home indicator float over the screen, so heroes and the glass tab bar reach the edges as they do on iOS 26.

**Props:** `caption`, `children` (screen content; a `TabBar` or `.fm-tabbar-wrap` inside it floats at the bottom), `theme` (forces `light` or `dark`). Showcase only; never ship it in the app.
