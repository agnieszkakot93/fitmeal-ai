# PlanCard

A subscription tier on the paywall: name, promise, price, annual equivalent, features.

**Props:** `tier` (`free` | `standard` | `premium`), `name`, `flag` (*Most popular*, *Best optimization*, *Coming soon*), `promise`, `price`, `period`, `subprice`, `features`, `selected`, `soon`.

- Standard is always visually the default: pre-selected with *Most popular*.
- Premium is `soon` in Phase 1.
