# MacroLine

The inline nutrition summary used everywhere a meal is named: *520 kcal · 44 P · 52 C · 12 F*.

**Props:** `kcal`, `protein`, `carbs`, `fat` (any may be omitted), `size` (`lg`).

- Write kcal first, then P / C / F in that order, always with the coloured dot and letter.
- Omit carbs and fat on compact cards; never omit protein.
