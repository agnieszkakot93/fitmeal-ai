# OnboardingProgress

A back button, a thin progress bar and a step count across the 14 onboarding steps.

The steps are: welcome, 18+ confirmation, consent and health notice, goal, body data (optional), calories, macros, meals per day, calorie distribution, allergies, other exclusions, preferences, budget, and meal prep with cooking. Sign in with Apple comes after, when the first plan is generated.

**Props:** `step`, `total` (default 14).
