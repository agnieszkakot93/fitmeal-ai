# SelectCard

A large tappable option with title and one-line explanation; the building block of onboarding questions.

**Props:** `title`, `description`, `icon`, `meta` (right-aligned value, e.g. *−500 kcal*), `selected`, `onChange`, `multiple` (square mark, checkbox semantics).

- Titles are the choice (*Lose fat*), descriptions say what FitMeal will do with it (*We'll suggest ~500 kcal under maintenance*).
- Always offer an escape option (*Custom target*) at the end of the list.
