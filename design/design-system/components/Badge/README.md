# Badge

A small label for state: meal-prep portion, prepare fresh, cooked, allergy, check this, plan tier.

**Props:** `tone`: `neutral`, `basil` (on target, best fit, cooked), `paprika` (meal prep, changed by FitMeal), `warning` (intolerance, check this, avoid when possible), `danger` (allergy), `premium`, `solid`. Also `icon`, and children of one to five words.
