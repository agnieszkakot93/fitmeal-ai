# Toggle

An iOS-style switch row for on/off settings and plan options.

**Props:** `label`, `description`, `checked`, `onChange(bool)`, `disabled`. The whole row is the hit target.

In a list group with a leading icon (*Sync with iCloud* on Profile and 01c), wrap it in a row with 16px side padding and the icon before it; the description says where the data goes (*Only in your private iCloud. We can't read it.*).
